# Mobile UI guidance

When developing UI changes for the mobile apps, follow the official platform design guidance:

- iOS (`iosApp`): Apple's [Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines).
- Android (`androidApp`): Google's [Material Design](https://m3.material.io).

If a user proposes a UI change that contradicts the official guidance, point this out to the user and
propose an alternative that complies.
